Module Pédagogique

Comprendre DoS vs DDoS en Profondeur

Tout ce qu'il faut savoir pour votre exposé : définitions exactes, mécanismes techniques et vecteurs d'attaque.

Attaque Unicast

Denial of Service (DoS)

Une attaque DoS implique une unique source (un seul ordinateur ou une seule connexion Internet) qui s'attaque à une cible pour saturer ses ressources (bande passante, connexions simultanées, cycles processeur).

  • Facilement identifiable par les pare-feux (filtrage d'IP simple).
  • Nécessite souvent une grande puissance de la machine source pour saturer une grosse cible.
  • Origine traçable rapidement par les administrateurs réseau.
Complexité : Faible à Moyenne Contrer : Blacklisting IP
Menace Majeure
Attaque Distribuée (Botnet)

Distributed Denial of Service (DDoS)

Le DDoS utilise des milliers ou millions de machines compromises (appelées bots ou zombies formant un Botnet, souvent des objets connectés IoT non sécurisés) pour submerger simultanément la cible depuis le monde entier.

  • Impossible de bloquer avec un simple bannissement d'IP (adresses multiples & changeantes).
  • Volume de trafic titanesque pouvant dépasser 50 à 100 Terabits par seconde.
  • Nécessite des solutions de scrubbing cloud (Cloudflare, Akamai, etc.).
Complexité : Élevée Contrer : Scrubbing Centers

Les 3 Couches d'Attaque Principales (OSI)

COUCHE 3 & 4 (RÉSEAU / TRANSPORT)

Attaques Volumétriques

Inondent la bande passante avec des paquets inutiles (ex: UDP Flood, SYN Flood, ou Amplification DNS/NTP). Le tuyau réseau est saturé.

Exemple : Falsification d'adresse IP (Spoofing) pour amplifier la réponse.
COUCHE 7 (APPLICATION)

Attaques Applicatives

Ciblent directement les processus web (ex: HTTP Flood, Slowloris). L'attaque simule des connexions légitimes très lentes pour épuiser les sockets du serveur web (Apache/Nginx).

Exemple : Demander des requêtes SQL lourdes en boucle sur une base de données.
PROTOCOLAIRE

Épuisement d'État (State Exhaustion)

Visent les équipements de sécurité intermédiaires (pare-feux, équplicateurs de charge). Submergent les tables d'état des connexions TCP.

Exemple : Connexions TCP semi-ouvertes (SYN packets sans ACK final).

Anticiper les Questions du Professeur

Q : Quelle est la différence exacte entre DoS et DDoS ?

R : Le DoS provient d'une seule machine (facile à bloquer par IP). Le DDoS utilise des milliers de machines réparties dans le monde (Botnet), rendant impossible le simple blocage d'adresse IP.

Q : Comment les pirates créent-ils des botnets géants ?

R : Ils scannent Internet à la recherche d'objets connectés (caméras IP, routeurs domestiques) qui utilisent encore leurs mots de passe d'usine par défaut (ex: admin/admin).

Q : Peut-on être puni pour une attaque DDoS ?

R : Oui, c'est un délit lourd puni par la loi (jusqu'à plusieurs années de prison et amendes colossales selon le pays, ex: art. 323-2 du Code pénal en France).
